---
name: Custom role scope
description: The user's chosen scope for administrator access management.
---

The user chose custom roles with configurable permissions rather than an Admin/Customer-only role system.

**Why:** The user requested a Settings page to add, edit and delete admin users and roles, and explicitly selected “Custom roles with permissions”.

**How to apply:** Preserve custom-role management when extending the admin dashboard. Do not simplify access management back to only two fixed roles without asking the user.
